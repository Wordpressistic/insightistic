# Security policy

Please do not disclose suspected vulnerabilities in a public issue or pull request.

Use a private GitHub Security Advisory for this repository when available. If that option is unavailable, contact WordPressistic privately through [wordpressistic.com](https://wordpressistic.com/) and include the affected version, reproduction steps, impact, and any safe mitigation.

Do not include API keys, service-account JSON files, license keys, customer data, or other secrets in a report or repository issue.

Security fixes should be tested against the minimum supported versions before a public release. See [`docs/RELEASING.md`](docs/RELEASING.md) for the local release gates.
