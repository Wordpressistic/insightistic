# Insightistic 4.7.3

## Focus

This release updates the WordPress plugin only. The Insightistic app/API repository was audited read-only and was not modified.

- The dedicated Speed Test now uses the dashboard PageSpeed visual system: category summary cards, a device score ring, Core Web Vitals, priority opportunities, and diagnostics.
- Search Console connection checks support `sc-domain:` domain properties and automatically try the matching domain property when a URL-prefix property returns a permission error.
- Cloud AI calls use an endpoint-scoped 60-second timeout for larger Search Console and PageSpeed payloads.
- AI results now offer a print-ready Download Reports action containing the loaded report data and AI output; the browser can save it as a PDF.
- Legacy plan-limit fields are no longer displayed as a live AI balance. The account page only shows credits when the API returns the structured credit payload.

## App contract note

The audited app/API branch still counts AI insight requests against `ai_insight_limit`, does not expose structured live credit balances in its plugin entitlement response, and does not provide a plugin-facing PDF/report quota endpoint. The plugin therefore does not fabricate credit deductions or report limits. Enforcing 500 free monthly credits, charging 50 credits per analysis/report, allowing three free reports, and selling credit packs requires a separate app/API contract change outside this plugin-only release.
