# Insightistic 4.7.0

Released: 2026-11-04

Insightistic 4.7.0 is a WordPress.org-ready release focused on a fully free plugin experience, safer optional AI, and reliable IndexNow delivery.

## Highlights

- AI Insights use the optional Insightistic Cloud AI service with explicit consent and monthly credit visibility.
- Third-party AI provider settings and stored provider keys are removed during the upgrade migration.
- IndexNow can be used without an Insightistic account when the site owner opts in.
- IndexNow key-file writes use the WordPress Filesystem API with explicit permissions.
- Chart.js is bundled at version 4.6.1.
- All plugin modules are free and unlocked; an account is only needed for optional Cloud AI and hosted dashboard features.
- External-service documentation has been expanded in the WordPress.org readme.

## Compatibility

- WordPress 5.6+
- PHP 8.0+
- Tested up to WordPress 7.1
- GPL-2.0-or-later
