# Insightistic 4.7.2

## Focus

This release improves the WordPress plugin only. The Insightistic app/API repository was audited read-only and was not modified.

- AI results appear directly below the dashboard action row.
- Overview and Search Console KPI cards expose metric-specific AI improvement slots and improvement keys.
- Search Console and PageSpeed have the same manual AI action pattern.
- Top Posts falls back to a bounded GA4 page report and resolves root-level WordPress post permalinks locally.
- PageSpeed dashboard results use the detailed Lighthouse payload with category scores, AI readiness, Core Web Vitals, opportunities, and diagnostics.
- Cloud AI branding is consistently `Insightistic Cloud AI`; the model and skill-profile controls are no longer exposed.
- The connection test validates the account/license route without generating an AI response.
- AI credits moved from Settings to Account, with future-compatible monthly/purchased balance fields and the requested extra-credit pack links.
- Addon card sizing and action alignment were tightened.
- Structured AJAX/gateway errors are normalized before rendering, removing the `[object Object]` failure state.
- Cloudflare now validates the selected zone against the current WordPress hostname and reports GraphQL access-control failures with a clear token/zone action.
- Search Console permission guidance now identifies the exact property, and `sc-domain:` domain properties are supported correctly.
- Speed Test opportunity rows were made responsive and safe for long Lighthouse descriptions.

## App contract note

The audited app/API branch currently accepts the plugin AI request, but its server-side usage service counts insight requests against `ai_insight_limit`. The audited license entitlement response did not expose the requested monthly/purchased credit fields, and the app billing UI/API did not expose a credit-pack checkout route. The plugin therefore renders credit data when the API supplies it and keeps the pack links configurable, but it does not fabricate a live balance or claim that checkout is complete. Enforcing 500 monthly credits, charging 50 credits per analysis, and selling credit packs requires an app/API change outside this plugin-only release.
