# Insightistic 4.7.1

Released: 2026-11-04

Insightistic 4.7.1 is a security-hardening release for analytics payload handling, settings imports, encryption-secret generation, and frontend tracking namespacing.

## Security and privacy fixes

- New encryption secrets are generated with secure random bytes only. If secure random generation fails, encryption stops instead of reusing WordPress salts.
- Decoded analytics JSON is recursively sanitized and type-normalized before AI, Cloudflare, and WooCommerce handlers use it.
- Settings imports use a strict allowlist of non-secret options and type-based sanitization before `update_option()`.
- Frontend tracking uses the `insightisticTracking` namespace and `insightistic_cid` cookie name.
- Existing legacy ciphertext decryption remains available only for upgrade migration; new encryption does not use WordPress salts as a secret source.
